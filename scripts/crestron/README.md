# Crestron build/helper scripts (WIP)

Home for any Crestron-side tooling (analogous to `scripts/qsys/compile.py`).

Note: unlike Q-SYS, Crestron compilation generally relies on proprietary IDE
toolchains (SIMPL Windows, Visual Studio + Crestron SDK), so a fully automated
`compile.py` equivalent may not be feasible for every target. Document the
required manual/toolchain steps here as skills are built.
