# For Whom is this Guide Intended?

This tutorial assumes the reader has at least a working knowledge of the SIMPL programming environment. This includes the ability to configure a new program (define the hardware), and to interconnect user-interfaces (e.g., a touch screen) and system outputs (e.g., a relay). Knowledge of the SIMPL logic symbols is not required, but is helpful in understanding some of the examples presented herein.

This guide is intended to be the complete SIMPL+ programming guide, appropriate for the beginning SIMPL+ programmer, or the expert programmer looking for a refresher course. This guide, along with The SIMPL+ Reference Manual should provide all the information needed for any SIMPL+ programmer.
