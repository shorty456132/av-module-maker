# File Time and Date Functions Overview  
  
These versions of the Time and Date functions in a given SIMPL+ program are used to retrieve information about the current date and time from the file info structure returned from [FINDFIRST](<File_First.htm>)/[FINDNEXT](<FindNext.htm>). Values can be retrieved as text strings i.e. "January" or integer values. Typically, integer values are used if computations need to be performed (i.e. when the date is the 25th, perform a specific action).
