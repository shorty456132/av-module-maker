# String Formatting & Printing Functions Overview

The printing functions are used to take INTEGER and STRING type arguments in a SIMPL+ program, format them in a user specified way, and send the output to either the CONSOLE of the control system or to another STRING.

The functions are:

[MakeString](<MAKESTRING.htm>)

[Print](<PRINT.htm>)

[String Concatenation](<STRING_CONCATENATION.htm>)

[String Operators](<String_Operators.htm>)

[Trace](<TRACE.htm>)
