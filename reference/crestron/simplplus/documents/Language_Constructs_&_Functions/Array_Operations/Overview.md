# Array Operations Overview

Array Operations functions are used to perform generalized operations on arrays, such as getting bounds and setting the elements of an array to a known value in a given SIMPL+ program.

Operation |  Description  
---|---  
[GetNumArrayCols](<GetNumArrayCols.htm>) |  Finds the number of columns in a two-dimensional array or the size of the array for a one-dimensional array.  
[GetNumArrayRows](<GetNumArrayRows.htm>) |  Returns the number of rows for two-dimensional arrays or string arrays. Returns 0 for one dimensional arrays or strings.  
[GetNumStructureArrayCols](<GetNumStructureArrayCols.htm>) |  Returns the number of columns in a structure array.  
[ResizeArray](<ResizeArray.htm>) |  Changes the allocated size of the string array to NewNumElements of NewSize bytes or the integer array to NewNumElements rows of NewSize columns.  
[ResizeStructureArray](<ResizeStructureArray.htm>) |  Changes the allocated size of the structure array to NewSize elements.  
[SetArray](<SetArray.htm>) |  Sets every element of ARRAY_NAME to the INIT_VALUE.
