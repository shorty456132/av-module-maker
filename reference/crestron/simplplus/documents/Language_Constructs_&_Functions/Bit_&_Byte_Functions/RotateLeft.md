# RotateLeft

Name:

RotateLeft

Syntax:

INTEGER RotateLeft( INTEGER X, INTEGER Y );

Description:

Rotate X to the left (more significant direction) by Y bits; full 16 bits used. Same as {{ operator.

(refer to [RotateRight](<RotateRight.htm>) explanation)

Parameters:

X is the INTEGER to have bits rotated

Y is the amount of bits to rotate

Return Value:

An INTEGER containing the result of the rotated bits.

Example:

INTEGER X, Y, result;

result = RotateLeft( X, Y ); 

Version:

X Generation: Not Supported

2-Series: SIMPL v2.03.18 and later
