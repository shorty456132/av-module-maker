# #CRESTRON_SIMPLSHARP_LIBRARY

Name:

#CRESTRON_SIMPLSHARP_LIBRARY

Syntax:

#CRESTRON_SIMPLSHARP_LIBRARY "<SIMPL# Library Name>"

Description:

Directs the compiler to include code from a Crestron SIMPL# library. The module name specified is the library filename without the CLZ extension.

Example:

#CRESTRON_SIMPLSHARP_LIBRARY "MyCrestronLibrary"

Directs the compiler to include the Crestron SIMPL# Library, "MyCrestronLibrary.clz".

Version:

3-Series

SIMPL v4.02.00 and later

4-Series

SIMPL v4.14.06 and later
