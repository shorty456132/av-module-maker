# Compiler Error 1706

**library error: Error including SIMPL# Library: ‘<clz_name>’**

A problem exists within a SIMPL# Library. This could be due to a signing issue or the SIMPL# Library being built incorrectly. The SIMPL# Library should be rebuilt again.
