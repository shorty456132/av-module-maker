# GetModelNumber

Name:

GetModelNumber

Syntax:

GetModelNumber

Description:

Returns the product name.

Example:

FUNCTION DisplayProduct()

{

PRINT( “This is a %s”, GetModelNumber() );

}

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: v <> and above
