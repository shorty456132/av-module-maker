# INHERIT

Name:

INHERIT

Syntax:

INHERIT

NOTE: This is not a declaration but a declaration modifier. It works only in conjunction with the STRING declaration keyword. 

Description:

The encoding of the string will be forced to the module’s default inherited encoding type. Inherited encoding types can either be from the parent module or calling program. These are both set by the compiler directives, [#ENCODING_INHERIT_FROM_PARENT](<_ENCODING_INHERIT_FROM_PARENT.htm>) and [#ENCODING_INHERIT_FROM_PROGRAM](<_ENCODING_INHERIT_FROM_PROGRAM.htm>).

Example:

INHERIT string s[100];

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: v <> and above
