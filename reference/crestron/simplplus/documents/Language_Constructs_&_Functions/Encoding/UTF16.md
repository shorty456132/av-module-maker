# UTF16

Name:

UTF16

Syntax:

UTF16

NOTE: This is not a declaration but a declaration modifier. It works only in conjunction with the STRING declaration keyword. 

Description:

The encoding of the string will be forced to UTF16 if the declaration is preceded by the UTF16 modifier.

Example:

UTF16 string s[100];

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: Supported

4-Series: Supported
