# TRY-CATCH

Name:

TRY-CATCH

Syntax:

TRY { <statements> } CATCH { statements }

Description:

TRY-CATCH blocks catch and handle exceptions generated by working code. Exceptions can be caught and handled in the CATCH portion of the block. The exception can also be evaluated using either the [GetExceptionMessage](<GetExceptionMessage.htm>) or [GetExceptionCode](<GetExceptionCode.htm>) function.

Example:

Function MyFunc( INTEGER index )

{

INTEGER intArr[10];

TRY

{

intArr[index] = 1;

Print( “array index set” );

}

CATCH

{

Print( “array index out of bounds: %d”, index );

}

}

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: v <> and above
