# Edit Menu

The Edit Menu contains the typical Windows commands and hot keys as well as some commands that are peculiar to SIMPL+.

Interactive: click on an Edit Menu command to learn more about it. If you place your cursor on a hot spot, a screen tip will display.

NOTE: Only Select All, Find Next, Bookmarks, Insert Category and Preferences are enabled at this time.
