# What is Needed to Use SIMPL+?

SIMPL+ version 2.0 requires a CNX-series control processor and SIMPL v1.23 or later.

SIMPL+ version 3.0 accompanies SIMPL v2.00 or later, and may be used to program either a 2-Series control system or a CNX-series control system.
