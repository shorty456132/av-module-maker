# ASCII

Name:

ASCII

Syntax:

ASCII

NOTE: This is not a declaration but a declaration modifier. It works only in conjunction with the STRING declaration keyword. 

Description:

The encoding of the string will be forced to ASCII if the declaration is preceded by the ASCII modifier.

Example:

ASCII string s[100];

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: Supported

4-Series: Supported
