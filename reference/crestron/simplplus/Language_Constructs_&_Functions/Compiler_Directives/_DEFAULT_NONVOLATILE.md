# #DEFAULT_NONVOLATILE

Name:

#DEFAULT_NONVOLATILE

Syntax:

#DEFAULT_NONVOLATILE

Description:

Program variables retain their value if hardware power is lost. The compiler will default all variables declared within the SIMPL+ module as nonvolatile. Individual variables can use the Volatile keyword to override this default. See also: [#DEFAULT_VOLATILE](<_DEFAULT_VOLATILE.htm>).

Example:

#DEFAULT_NONVOLATILE

Version:

X Generation: Not Supported. On X Generation Systems, all global variables are Non Volatile.

2-Series: SIMPL v2.01.05 and later
