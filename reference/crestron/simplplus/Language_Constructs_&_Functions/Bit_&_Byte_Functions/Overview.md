# Bit & Byte Functions Overview

These functions perform bit and byte masking operations in a given SIMPL+ program.

Function |  Description  
---|---  
[Bit](<BIT.htm>) |  Determines the state of a specified bit in a particular byte of a given string.  
[Byte](<BYTE.htm>) |  Returns the integer equivalent of the byte at position SOURCE_BYTE within a SOURCE string.  
[High](<HIGH.htm>) |  Returns the upper most significant 8-bits of an Integer.  
[HighWord](<HighWord.htm>) |  Returns the upper 16 significant bits of a LONG_INTEGER.  
[Low](<LOW.htm>) |  Returns the lower least significant 8-bits of an Integer.  
[LowWord](<LowWord.htm>) |  Returns the lower 16 significant bits of a LONG_INTEGER.  
[LowerChar](<LowerChar.htm>) |  Converts the given character to lower case, so long as the character is between 'A' (0x41) and 'Z' (0x5A).  
[UpperChar](<UpperChar.htm>) |  Converts the given character to upper case, so long as the character is between 'a' (0x61) and 'z' (0x7A).  
[SetByte](<SetByte.htm>) |  Sets the byte at the position given by POSITION in the string given by SOURCE to the value in VALUE.
