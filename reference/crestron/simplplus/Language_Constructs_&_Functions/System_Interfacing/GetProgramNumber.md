# GetProgramNumber

Name:

GetProgramNumber

Syntax:

GetProgramNumber

Description:

Returns which program the module is executing from.

Example:

FUNCTION DisplayProgramNumber()

{

PRINT( “This is the %d”, GetProgramNumber() );

}

Version:

X Generation: Not Supported

2-Series: Not Supported

3-Series: v <> and above
