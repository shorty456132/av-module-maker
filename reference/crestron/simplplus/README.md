# SIMPL+ Reference

Help docs / examples for SIMPL+ (`.usp`/`.ush` language, C-like syntax,
INPUT/OUTPUT signal model, compiled inside SIMPL Windows).

The doc corpus lives in `documents/` (mirrors `reference/qsys/documents/`); the
`simplplus-create` / `simplplus-revise` skills search that subfolder via a
read-only Explore subagent. Each doc keeps a `> Source: <url>` header line.
